DWG 를 열지 못했습니다

이 앱은 보통 DWG 를 자동으로 열지만, 지금은 실패했습니다. 흔한 원인:
• 오프라인 상태인데 DWG 엔진이 아직 앱에 포함되지 않음
  → 온라인에서 한 번 열면 이후 캐시됩니다. 완전 오프라인은 vendor/libredwg 를 포함해 빌드하세요 (BUILD.md).
• 매우 오래된/손상된 DWG

대안 — DXF 로 변환 (1분)
1. PC에 무료 ODA File Converter 설치 (opendesign.com → Guest)
2. 출력 형식 DXF 로 변환 → 변환된 .dxf 를 이 앱에서 열기
AutoCAD 가 있으면 다른 이름으로 저장 → DXF.
